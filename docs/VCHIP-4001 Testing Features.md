# VCHIP-4001 Specification: LowlandTech.Testing.Features

## Overview

**LowlandTech.Testing.Features** provides a composable, metadata-driven **Given-When-Then** testing framework tailored to Vylyrian projects. It aims to standardize test coverage reporting, integrate BIP-compliant tagging (`NodeId`, `TaskId`, `UseCaseId`), and support pure logic as well as EF Core integration scenarios.

This specification defines:

* Behavior-driven scenario modeling
* Metadata conventions
* Test reporting
* Usage guidelines

---

## Goals

* Allow **test scenarios** to be documented declaratively with consistent Given-When-Then patterns.
* Enable **structured test metadata** (`Scenario Code`, `TaskId`, `UseCaseId`) to align coverage with specifications and BIP processes.
* Support **pure logic tests**, **in-memory EF Core integration tests**, and **browser-based flows**.
* Provide an **automated Markdown report generator** (`ltx report`) to produce easily shareable coverage reports.

---

## Features

### 1?? Scenario Attributes

Scenarios are described via the `[Scenario]` attribute. It supports:

* Minimal mode:

  ```csharp
  [Scenario("Given something", "When something happens", "Then something is expected")]
  ```

* Full metadata mode:

  ```csharp
  [Scenario(
    "VCHIP-4001-SC001",
    "Simple scenario title",
    "Given a simple context",
    "When an action occurs",
    "Then an outcome is expected")]
  ```

* Arbitrary step mode:

  ```csharp
  [Scenario(
    "VCHIP-4001-SC002",
    "Complex scenario",
    "Given context",
    "When action",
    "Then result",
    "And another check")]
  ```

### 2?? Metadata Binding

Each scenario can be further annotated:

| Attribute     | Purpose                                        | Example                                           |
| ------------- | ---------------------------------------------- | ------------------------------------------------- |
| `[NodeId]`    | Binds to a graph node (e.g., `vy.test.nodeid`) | `[NodeId("vy.test.nodeid")]`                      |
| `[TaskId]`    | Links to a BIP task                            | `[TaskId("VCHIP-4001-TK001")]`                    |
| `[UseCaseId]` | Associates with a specific use case            | `[UseCaseId("VCHIP-4001-UC001")]`                 |
| `[Then]`      | Defines outcome verification and UAC code      | `[Then("Outcome happened", "VCHIP-4001-UAC001")]` |

## Example Scenarios

From the project implementation:

### Simple Scenario

```csharp
[Scenario(
    "VCHIP-4001-SC001",
    "Simple scenario title",
    "Given a simple context",
    "When an action occurs",
    "Then an outcome is expected")]
public class ScenarioWithCodeAndTitle : WhenTestingFor<int>
{
    protected override int For() => 0;
    protected override void When() { }

    [Fact]
    [Then("Outcome happened", "VCHIP-4001-UAC001")]
    public void ShouldBeTrue() { 0.ShouldBe(0); }
}
```

### TaskId Scenario

```csharp
[Scenario("TaskId scenario", "When testing TaskId", "Then TaskId should be included")]
[TaskId("VCHIP-4001-TK001")]
public class ScenarioWithTaskId : WhenTestingFor<int>
{
    protected override int For() => 0;
    protected override void When() { }

    [Fact]
    [Then("TaskId included")]
    public void ShouldIncludeTaskId() { }
}
```

## Coverage Report Format

Reports generated by `ltx report` follow this Markdown structure:

```
# <Report Title>

## <Scenario Title>
**Scenario Code:** `<SC_CODE>`

> **Given:** <Given>
> **When:** <When>
> **Then:** <Then>

**Test Class:** `<ClassName>`

**Tags:** `<SC_CODE>`, `<TaskId>`, `<UseCaseId>`, `<NodeId>`

- ? `<MethodName>` — <Outcome Description> (`<UAC Code>`)
```

Example excerpt:

```
## Simple scenario title
**Scenario Code:** `VCHIP-4001-SC001`

> **Given:** Given a simple context
> **When:** When an action occurs
> **Then:** Then an outcome is expected

**Test Class:** `ScenarioWithCodeAndTitle`

**Tags:** `VCHIP-4001-SC001`

- ? `ShouldBeTrue` — Outcome happened (`VCHIP-4001-UAC001`)
```

## Assembly Extensions

To generate coverage reports:

**Synchronous:**

```csharp
assembly.GenerateCoverageReport("./coverage.md", "My Feature Report");
```

**Asynchronous:**

```csharp
await assembly.GenerateCoverageReportAsync("./coverage.md", "My Feature Report");
```

Command-line example:

```bash
ltx report ../MyTests.dll --file Coverage.md --title "My Project Feature Coverage"
```

## Base Classes

| Class                    | Purpose                        |
| ------------------------ | ------------------------------ |
| `WhenTestingFor<T>`      | Pure logic tests               |
| `WhenTestingForAsync<T>` | Async logic tests              |
| `WhenUsingDatabase<T>`   | EF Core integration tests      |
| `WhenUsingBrowser<T>`    | Playwright-based browser tests |

---

## Compliance and Conventions

* All scenario codes must use format: `VCHIP-4001-SC###`
* All UAC codes must use format: `VCHIP-4001-UAC###`
* `TaskId`, `UseCaseId`, and `NodeId` are optional but recommended for traceability
